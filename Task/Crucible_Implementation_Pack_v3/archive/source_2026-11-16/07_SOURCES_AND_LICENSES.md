# 07. Бесплатные источники и лицензии

Проверено по первичным страницам **15 ноября 2026 года**. Ссылки — конкретные источники для агента, не результат «берите подходящие картинки где-нибудь». В пакет не вложены шрифтовые файлы и чужие изображения. Сторонние ресурсы при установке нужно сохранять локально с применимыми уведомлениями и версией/hash.

## S1. Основной шрифт — Golos Text

- Официальный репозиторий: https://github.com/googlefonts/golos-text
- Каталог Google Fonts: https://github.com/google/fonts/tree/main/ofl/golostext
- Текст лицензии: https://github.com/google/fonts/blob/main/ofl/golostext/OFL.txt
- Лицензия: SIL Open Font License 1.1.
- Применение: весь UI, русский основной текст, англоязычные условия; веса 400/500/600/700. Получить только нужные webfont subsets latin/cyrillic; проверить символы математической навигации, а саму математику отдать действующему renderer.
- Не использовать платный вариант с сайта-посредника, если официальный источник доступен. Не вызывать Google Fonts API при каждом открытии страницы.

## S2. Заголовочный шрифт — Noto Serif

- Официальное описание и кириллица: https://notofonts.github.io/noto-docs/specimen/NotoSerif/
- Семейство: https://github.com/google/fonts/tree/main/ofl/notoserif
- Лицензия: https://github.com/google/fonts/blob/main/ofl/notoserif/OFL.txt
- Общие инструкции Noto: https://notofonts.github.io/noto-docs/website/use/
- Лицензия: SIL Open Font License 1.1.
- Применение: короткие H1/H2, ранг и важные имена предметов. Не подменять Noto Serif на Noto Serif SC/CJK: это другое семейство. Нельзя оставлять кириллицу fallback Georgia, когда латинский заголовок красивый.

## S3. Интерфейсные иконки — Lucide

- Источник: https://lucide.dev/
- Официальная лицензия: https://lucide.dev/license
- Репозиторий: https://github.com/lucide-icons/lucide
- Основная лицензия ISC; часть унаследованных иконок перечислена на странице под MIT. Сохранять оба применимых уведомления; не приписывать всю коллекцию CC0.
- Применение: навигация, поиск, часы, настройки, стрелки, открыть/закрыть, индикаторы статуса. 20–24 px, stroke 1.75, currentColor. Использовать уже установленную совместимую библиотеку либо закрепить одну версию.
- Имена для проверки экспорта в выбранной версии: `BookOpen`, `Library`, `Swords`, `Shield`, `Clock`, `Search`, `Settings`, `ChevronRight`, `Check`, `X`, `Menu`, `Archive`. Если имя в установленной версии другое, агент выбирает соответствующий **существующий Lucide** icon и фиксирует mapping, не добавляет вторую UI-библиотеку.

Общее объяснение лицензии: https://game-icons.net/about.html и https://game-icons.net/faq.html . Скачать SVG через страницу, выбрать одноцветный вариант на прозрачном фоне. Не копировать screenshot сайта. Для плеч/наручей временно использовать собственный простой силуэт по слоту или текстовую категорию: не выдумывать URL несуществующей иконки. SVG sword называется двухручным в библиотеке, но это только условная категория; все собственные мечи кампании по нашему канону одноручные.

В `THIRD_PARTY_NOTICES.md` перечислить применённые имена, автора, исходную страницу, CC BY 3.0 и факт модификации (например, recolor). Ссылка на лицензию: https://creativecommons.org/licenses/by/3.0/ . Не ограничиваться подписью «взято из интернета».

## S5–S7. Доступность и движение

S5: W3C, Contrast Minimum: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html . Основание чисел 4.5:1 для обычного текста и 3:1 для крупного.

S6: W3C, Non-text Contrast: https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html . Основание проверки значимых частей контролов/графики относительно соседнего фона.

S7: MDN, prefers-reduced-motion: https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion . Основание поддержки системного запроса на уменьшение движения. Реальная версия браузера проверяется на целевом устройстве.

Эти источники задают технические основания; эстетическая палитра и выбор типографики — наше решение. Ссылки не означают, что приложение уже соответствует WCAG целиком: требуется проверка реальной реализации.

## S8. Проверенный, но необязательный материал

- Crepe Satin: https://polyhaven.com/a/crepe_satin
- Лицензия Poly Haven: https://polyhaven.com/license
- Авторы карточки: Rico Cilliers / colormass, лицензия CC0 для этого материала.

Это бесплатный PBR-материал ткани, **не готовая белая драпировка с нужными складками**. Для этой версии НЕ внедрять 3D-рендер/набор PBR-карт только ради баннера. Используется наш ENV-SILK. Материал упомянут, чтобы не обещать, что найденная бесплатная «текстура шёлка» автоматически решает задачу изображённой ткани.

## 9. Собственные и сгенерированные элементы

Эмблема, пять рун, полосы XP, небольшие ауры и графические корешки создаются средствами CSS/SVG по спецификации. Отдельные сторонние игровые лицензии для них не заимствуются.

42 исходных иллюстрации производятся пользователем в выбранном им генераторе. Их использование/публикация регулируются условиями этого генератора; этот пакет не объявляет такие изображения автоматически CC0 и не переносит на них лицензии Lucide/Poly Haven. Хранить provenance: инструмент, дата, собственный prompt, использованные собственные референсы, подтверждение права использовать output. Не копировать официальные D&D-иллюстрации, логотипы или чужие готовые предметы как референс без необходимых прав.

План не требует покупки ассетов и не зависит от платного asset pack. Доступ пользователя к генератору — предоставленное им условие, а не обещание нулевой цены любого генератора для любого человека.

## 10. Реестр получения

Агент создаёт `assets/source-lock.json`: ID, URL страницы, фактический URL полученного файла, дата, hash, license, author, modifications, локальное место хранения. Во frontend URL внешнего источника не используется как hotlink. Сеть во время обучения не требуется для загрузки шрифтов/иконок/картинок после установки.

При смене источника/лицензии не брать сомнительный mirror. Временно использовать системный шрифт/текстовую иконку и честно отметить блокировку получения, а не встроить неизвестный шрифт из чужого скриншота.
