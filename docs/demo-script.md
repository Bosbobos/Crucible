# Пятиминутный показ

1. Объяснить цель: математическая практика начинается с задачи; теория закрывает конкретное затруднение. Открыть локальный UI и закреплённый план.
2. Начать задачу, записать решение, дождаться «Сохранено сервером». Открыть теорию с оглавлением, перейти на вкладку лаборатории, проверить прогноз и вернуться в ту же попытку. Нажать «К результату», проверить самооценку с учётом помощи и завершить. Сохранить вопрос.
3. Показать разделение источников истины: content — материалы, practice — факты, learning — выводы. Остановить learning, сохранить результат, вернуть learning и показать достижение курсора. Проверки повтора события находятся в tests/resilience.
4. Показать MCP-контекст и комментарий обычным клиентом SDK; агентское предложение не меняет оценку до owner approval. Интерактивный desktop-host демонстрируется отдельно после его регистрации.
5. Показать CRUD в собственной БД learning командой `scripts/demo/postgres-crud` (исходник — `scripts/demo/postgres_crud.py`), затем SQL isolation report и firewall evidence; 403, SQL CONNECT denial и TCP REJECT — три разных механизма. Полные команды сетевых проверок доступны в networking.md.
6. Показать реальные свидетельства assessment failover, rejoin, quorum election и restore в отдельный project. Для быстрого выступления использовать сохранённые результаты, а не обещать запуск всех аварий за минуту.

Команды демонстраций PostgreSQL, Redis и RabbitMQ со слайдов 5, 7 и 8 собраны в [scripts/demo](../scripts/demo/README.md).

Скриншоты браузерных испытаний: `.private/evidence/screenshots/`. Результаты SQL/firewall/backup/restore/failover — `.private/evidence/*.json`. Эти файлы относятся к синтетическому профилю; приватные копии vault и секреты в презентацию не включаются.
