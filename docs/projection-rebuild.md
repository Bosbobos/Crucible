# Перестройка learning

`scripts/python scripts/rebuild_learning_projections.py` переводит локальный демонстрационный стек в обслуживание: останавливает внешний gateway, reports и брокер, выдерживает ограниченный drain уже принятых запросов и запускает `service.rebuild` внутри learning.

Learning получает только минимальные факты через `/internal/practice/learning-facts` и опубликованный каталог content API, используя предназначенные ему scopes. Чужие SQL credentials отсутствуют. В собственной транзакции заменяет производные факты, каталог и cursors; сохраняет пользовательские настройки, историю планов и командные квитанции. После запуска брокера старые outbox-события не заменяют новые редакции.

На время команды оператор подключает learning к practice_api/content_api. Это техническое исключение bootstrap/reconciliation, а не постоянный вызов зависимостей при каждом плане. Сетевые подключения снимаются в finally. При действующем CRUCIBLE_EGRESS режим обслуживания требует отдельного временного разрешения; тестовый firewall предварительно откатывается.

После восстановления брокера replay выполняется для всех сохранённых outbox, включая published. Он запускается отдельно у каждого владельца, не общим dispatcher с доступом к четырём БД. Производные данные можно пересоздать, собственные настройки/планы learning — нельзя.
