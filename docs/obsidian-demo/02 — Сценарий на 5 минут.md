## Речь, которую полезно выучить

### О продукте

![[01 — Полный инструктаж#^position]]

### Об архитектуре — 25 секунд

> Content хранит опубликованные материалы. Practice фиксирует действия пользователя: черновик, помощь и результат. Learning получает факты через брокер и рассчитывает повторения. Reports делает фоновый экспорт. У каждого владельца своя база и роль; чужого SQL нет. Поэтому отказ расчёта не должен мешать сохранению решения.

### О согласованности — 20 секунд

> При завершении попытки факт и outbox записываются одной транзакцией. Брокер может доставить событие повторно, поэтому learning сохраняет receipt вместе с эффектом. Клиент видит отдельно подтверждение сохранения и cursor расчёта. Мы не обещаем, что сообщения никогда не повторяются.

### О надёжности — 20 секунд

> На отдельном стенде проверены синхронная PostgreSQL-репликация и переключение после аварии primary, трёхчленные quorum queues и потеря их лидера. Backup проверяется восстановлением в пустой project. Все узлы пока на одном ноутбуке, поэтому это демонстрация отказов процессов, а не защита от потери устройства.

## Быстрые команды для экрана

Команды просмотра, не останавливающие приложение:

```bash
cd /Users/ashentide/PycharmProjects/HighloadSecurity
docker compose ps --all
make doctor
scripts/firewall show
docker compose exec -T rabbitmq rabbitmqctl list_queues -p study name type messages_ready messages_unacknowledged
```

`firewall show` предполагает, что правила уже применены. Для демонстрации CRUD и SQL ACL отдельно:

```bash
scripts/python scripts/check_sql_isolation.py
```

Эта проверка создаёт и удаляет одну временную запись plan draft; итоговая собственная таблица не засоряется.
