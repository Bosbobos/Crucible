## Изоляция и firewall

- SQL: 4 own-DB соединения разрешены, 12 cross-DB запрещены; runtime не superuser.
- CRUD: временная запись успешно создана, обновлена, прочитана и удалена.
- Firewall: 16 разрешённых TCP-путей и 5 запрещённых; отдельный запрет нужного пути и его восстановление.
- Проверки выполнялись в Linux namespaces Docker Desktop; host rules не менялись.

Отрицательные пути: web → PostgreSQL, web → Redis, content → practice, practice → Redis, learning → practice. Общая Docker-сеть сама по себе не является доказательством allowlist; JSON относится к проверке netfilter.

> Они не являются MTTR/MTBF или статистическим SLO. Проверенная сохранность относится к подтверждённой контрольной записи в конкретном синхронном сценарии. Все узлы разделяют физический ноутбук. Финальный restore потребовал операторского продолжения; не скрывай это, если обсуждаешь автоматизацию.
