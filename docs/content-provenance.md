# Учебные материалы из Obsidian

14 ноября 2026 активный каталог полностью заменён материалами из указанного пользователем vault. Новые учебные условия, решения и объяснения при переносе не сочинялись.

- 57 карточек P-001–P-057: условие, три исходные подсказки, решение и Remember.
- Сохранены исходные ID, уровни, число частей и 25 используемых типов. Поля личных заметок, ответы пользователя, статусы и история не импортировались.
- Три конспекта: «Матожидание, дисперсия и индикаторы», «Условная вероятность и формула Байеса», «Уравнения первого порядка»; отдельно «Карта приёмов».
- Из Dataview перенесены 14 интерактивных блоков как данные: микрозадачи, задача-мотиватор и возврат, выбор приёма, лаборатория. Исходный JavaScript не исполняется. Три сценария лаборатории — пары ОО, совпадения дней рождения, серии — адаптированы из исходного виджета, включая формулы.

Конспект связан с 14 карточками по существующему каталогу `extra/types.json`. Для других 43 карточек он отсутствует; дополнительные тексты не создавались. Конспекта по SVD в этой папке нет. Ссылки на учебники и соседние материалы сохранены как ссылки/библиографические указания; содержимое внешних файлов не загружалось. Контрольные PDF не использовались.

`content/vault-import.json` содержит относительные исходные пути и SHA-256 всех 61 учебных файлов. Все 81 файлы оригинального vault остались неизменными. Из карточек исключены «Мои попытки» и личные поля frontmatter. Перед публикацией проверены структура, ссылки, контрольные суммы и отсутствие утечки личных полей.

`review.status: source_preserved` означает сверку импорта с источником. Математическая экспертная рецензия не выполнялась. Исходное `source: classic` сохраняется в provenance; это не установление первоначального автора классической задачи.

Семейства независимых вариантов в vault не размечены. Поэтому карточки консервативно объединены по исходному типу: перенос навыка не подтверждается на основании выдуманной разметки. Возможное сопоставление с curriculum v2 остаётся отдельной работой. 57 исходных карточек не означают готовность целевого банка из 264 карточек.

Импорт выполняет `scripts/import_vault_content.py SOURCE --output NEW_DIRECTORY`. Он читает только карточки, конспекты и каталог типов, не меняет vault, не исполняет Dataview и не перезаписывает существующий output. Новая публикация выполняется через API content. Прежние release и закреплённые старые попытки сохранены для истории; в активном каталоге сгенерированных карточек нет. Личная история из vault — отдельная миграция, здесь она не выполнялась.

При разбиении конспекта на страницы вопросы самопроверки должны быть видны сразу. Рендерер показывает `[!quiz]` обычным открытым блоком, даже если в исходном Obsidian он помечен `-` или `+`; вложенные ответы и решения сохраняют отдельное раскрытие. Это устраняет страницы с одним свёрнутым заголовком в конспектах по Байесу и уравнениям первого порядка без изменения исходного vault и опубликованного учебного текста. Регрессионная проверка `apps/web/e2e/callouts.spec.ts` читает оба перенесённых конспекта из `content/` и проверяет видимость всех семи вопросов, отдельное раскрытие ответов и сохранение их состояния при перелистывании на широком и мобильном экранах.

Запуск этой проверки: из `apps/web/` выполнить `npx playwright test --config playwright.callouts.config.ts`. По умолчанию она использует отдельный Vite на порту 4175 с подменёнными API; `CRUCIBLE_TEST_ORIGIN=http://127.0.0.1:18080` проверяет установленный интерфейс с теми же подменёнными API, без изменения учебных данных.

Проверки: 23 backend-теста, включая import/privacy/contracts и деградацию; браузерные сценарии проверяют полный каталог, исходные вопросы и ответы, лабораторию, отсутствие выдуманной теории, callout-блоки и мобильный экран. Свидетельства находятся в `.private/evidence/vault-content-import.json`, `pytest-vault-content.txt`, `browser-vault-content.txt`.
