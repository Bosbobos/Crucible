# Владельцы

| Объект / команда | Владелец | Хранилище |
|---|---|---|
| Bundle, release, каталог, ядра, теория, защищённые решения | content | content_db |
| Попытка, редакции, таймер, помощь, самооценка, вопрос, комментарий | practice | practice_db |
| Предложение фактического исправления и подтверждение владельцем | practice | practice_db |
| Проекции фактов/каталога, политика v1, настройки, дневные планы | learning | learning_db |
| Временная сводка с ключом ревизии и учебной даты | learning | Redis |
| Job, переносимый JSON/Markdown и checksum manifest | reports | reports_db |
| MCP tools/resources и композиция контекста | study-mcp | собственной БД нет |
| Аварийный неподтверждённый черновик и ожидающая команда | web | localStorage браузера |

Ни один сервис не обращается к чужой БД. Каждому владельцу соответствует отдельный `postgres-<owner>`, volume и сеть `<owner>_storage`; чужие БД и роли в этом экземпляре не создаются. HTTP-права, SQL-права и запрет TCP к чужим PostgreSQL проверяются раздельно. Миграционные роли отделены от runtime; runtime не является superuser и не имеет CREATE в public.

Старый vault не является вторым writable runtime-хранилищем. Данные dry-run приватны, оригинальные ID/тексты/неизвестные времена сохраняются. Фактический cutover личной истории ещё не выполнен.
