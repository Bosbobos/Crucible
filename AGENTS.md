# Crucible

- Общение и документация — по-русски; условия, подсказки и решения — по-английски.
- Для локального Python использовать conda `IAD`; зависимости проекта изолировать в `.deps/`.
- В UI не использовать выпадающие списки, включая нативный `<select>`. Варианты выбора показывать на странице; формулы в названиях и метаданных рендерить как математику.
- Приоритет требований: `Task/ADR_003_Domain_Microservices.md` → `Task/ADR_MCP_and_service_boundaries.md` → `Task/TZ_Crucible.md`.
- Не изменять исходный Obsidian-vault. `.private/` содержит приватные копии и никогда не публикуется.
- Не открывать контрольные варианты/holdout при авторинге и обычной подготовке.
- Владельцы: content — опубликованные материалы; practice — факты; learning — расчёты и планы; reports — задания и артефакты. Нет общего ORM и чужого SQL.
- Изменяющие команды: авторизация, command_id, проверка ревизии, транзакционная квитанция; значимые факты и outbox в одной транзакции.
- Учебный агент создаёт комментарии и предложения. Подтверждение исправления — только владелец через UI.
- Не заявлять готовность P/D без фактических проверок, включая firewall, failover, restore и MCP-host.
